# AI 大模型应用开发学习笔记

## 📌 项目简介
这是我在学习 AI 大模型应用开发过程中的代码仓库。记录了从基础概念到实际调用大模型 API 的完整过程，包含各种小实验和实用脚本。

## 🛠️ 技术栈
- Python 3.10
- OpenAI API / 百度千帆 / 智谱GLM
- Git / GitHub

## 📂 项目结构
- `basics/`：Python 基础语法练习
- `llm_demos/`：大模型 API 调用Demo（开发中）
- `学习笔记.md`：日常学习记录

## 🚀 如何运行
1. 克隆项目：`git clone https://github.com/qzis238/ai_2026.git`
2. 安装依赖：`pip install -r requirements.txt`（后续添加）
3. 运行脚本：`python llm_demos/demo01.py`
