### ⚠️ 遇到的经典踩坑与解决
- **坑1：文本文件后缀陷阱**
  - *问题*：Windows 默认隐藏扩展名，新建文本文件变成了 `学习笔记.md.txt`。
  - *解决*：在文件夹“查看”中勾选“文件扩展名”，手动重命名删掉 `.txt`。
- **坑2：推送被拒绝 `! [rejected] main -> main (fetch first)`**
  - *问题*：本地和云端都有新提交，产生了冲突。
  - *解决*：先执行 `git pull origin main` 拉取云端代码并合并。
- **坑3：误入 Vim 编辑器不知如何退出**
  - *问题*：执行 pull 时弹出了黑底白字的 Vim 界面。
  - *解决*：按 `Esc` 键，输入 `:wq` 然后回车（保存并退出）。

### 🚀 Git 核心命令小抄
```bash
git status              # 查看当前状态
git add .               # 把所有改动添加到暂存区（购物车）
git commit -m "描述"    # 提交到本地仓库（结账）
git push origin main    # 推送到 GitHub 云端
git pull origin main    # 拉取云端最新代码（推送报错时先执行）
```
